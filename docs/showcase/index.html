为什么明明要顺序算的任务，能变成 GPU 上的一次数组运算

作物模型里真正的"顺序"只有一个方向：一块田的今天依赖它自己的昨天。不同田块、不同参数组之间没有任何依赖。所以两层循环可以交换顺序：不再是"对每块田，跑完它的 3287 天"，而是"对每一天，让所有田块一起做同一件事"。内层那件事对十万块田是完全相同的算式，只是数字不同，这正是 GPU 擅长的形状：一条指令，十万个数。Fortran 做不到不是因为它慢，而是它把每次运行绑死在一个进程里：全局状态、按文件名读输入、每天写文件，一块田一个进程，换不了循环顺序。

Fortran
for 田块 in 十万块:
    for 天 in 3287 天:
        state = 日步(state)
    写 99 个文件
Agri-JAX
for 天 in 3287 天:            ← scan 把这层循环编译进图

02 · 过程函数是什么，规则为什么是这三条

模型没变，变的是每个过程怎么写

Agri-JAX 里的每个过程仍然是农学家熟悉的那条方程。变化只有一点：过程读什么、改什么，全部写在签名上。下面用叶面积增长做例子，再解释三条规则各自堵住了什么问题。

一个过程长什么样：叶面积增长

这就是 CERES 里的叶面积扩展：ΔLAI = 展叶速率 × 今日积温 × 水分胁迫因子，只在营养生长期发生。函数从"昨天的状态"里读 LAI、生育期和土壤水，从"品种参数"里读展叶速率，从"今日天气"里读积温，算出今天的 LAI 写回状态。没有别的输入，也没有别的输出。这不是新模型，是把原来散落在全局变量里的读写关系摆到明面上。

规则一为什么：纯函数，因为隐藏状态会撞车

Fortran 模型里很多子程序通过 COMMON 块和 SAVE 变量共享状态：一个子程序悄悄改了一个数，另一个子程序在别处读到。一次只跑一块田时没问题。要十万块田同时跑，这些共享的格子就会互相覆盖，谁也说不清里面是哪块田的数。纯函数把每块田的状态放进它自己那一行，读什么改什么都在签名上，十万行互不打扰；反向求导也需要这个，因为要沿着明确的读写关系倒着走。

规则二为什么：用 where 分支，因为十万块田不在同一个生育期

写 if 生育期 == 营养生长 的时候，程序只能走一条路，但同一天十万块田里有的在出苗、有的在灌浆。where 把两个分支都算出来，再按每块田自己的条件挑：营养生长期的取增长值，其它的取零。每块田拿到自己那一条路，整列仍然是一次数组运算。梯度也一样沿着被选中的分支流回去。

规则三为什么：不写循环，因为循环是运行时的事

土壤有 37 层，Fortran 用 for 循环从上到下一层层算。同样的计算写成对整个"层"维度的一次运算，37 层一起出结果，十万块田就是 37 × 十万的一张表。时间循环由 scan 接管，样本循环由 vmap 接管，过程作者两个都不用管。这样过程代码里只剩方程本身。

一天是怎么拼起来的：过程按顺序接力

模型 = 状态的定义 + 一列有顺序的过程。每天从天气开始：算潜在蒸散，分配截光，作物物候和生长，多作物争水，土壤水再分配，最后写出诊断量。每个过程只碰它声明过的字段，所以能画出这张数据流图，能替换其中任何一个（把桶模型换成 Richards，把气孔阻力换成神经网络），也能逐个对照参考模型验证。这一列跑完，就是 Fortran 里的一天。

04 · 顺序模型做不到的事

一次反向传播，全部参数的梯度

前向沿天数走一遍，反向沿同一条路走回来，每个参数对产量的影响同时算出。有限差分要对每个参数各跑一次。

前向：状态逐日推进反向：伴随量逐日回传参数灵敏度 ∂产量/∂参数 示意

下面每一条优势都配一个"为什么"的动画。滚动到视野内自动播放，也可以点重播。

为什么一次反向就够，有限差分却要跑 P+1 次

有限差分要对每个参数各扰动一次、各跑一遍前向：30 个参数就是 31 次九年模拟。反向模式把链式法则沿同一张计算图倒着走一遍，所有参数的导数在一趟里同时累积，成本约等于几次前向，且与参数个数无关。

为什么高维标定不再靠撒点

拉丁超立方是在参数空间里撒点后挑最好的，维数一高样本就稀得像没撒。有了梯度，每一步都知道往哪走，几十步到谷底；成本几乎不随维数增长，七个站点一百多个参数联合标定就变得可行。

为什么能说清哪些参数"辨识不出来"

损失面在有的方向陡、有的方向平。平的方向就是数据约束不住的参数组合，比如只有 ET 观测时的 Ksat 与 λ。Fisher 信息矩阵是雅可比的转置乘雅可比，一次反向传播就能算，它的特征值谱直接给出可辨识方向的个数。

为什么是一千条短链，不是四条长链

NUTS 每一步都要梯度，一条链是串行的，每步有固定延迟。但 GPU 上四条链和一千条链在 vmap 里花的时间一样多。所以正确的形态是很多条短链同时采样，总样本数不变，墙钟从几十小时降到一小时。

为什么能把神经网络嵌进机理模型里训练

只要整条链可微，损失对网络权重的梯度就能穿过后面的机理过程流回来。于是可以只把最不确定的那个过程换成小网络，用通量塔的 ET 端到端训练，其余过程照旧守恒、照旧可解释。

为什么能回答"哪场雨决定了收成"

反向传播不只对参数求导，对每一天的降雨、初始含水量这些输入也一样。伴随量沿季节倒着流回去，每一天的降雨对最终产量的边际贡献就同时得到，一条曲线回答归因问题。
